# Changelog

## 0.1.0 (2026-10-26)

- First release: the 24 published core browser tools (navigation,
  snapshot, interaction, forms, dialogs, tabs, console, network)
  over an injectable snapshot-driven browser executor, with the
  element/target pairing and wait/tab validation rules in the core.
- One bin serves the CLI and a stdio MCP server (`mcp` subcommand).
